Agente Local Python (Zero-Config)

Los navegadores aíslan las tramas ARP e ICMP por seguridad. Ejecuta este script estándar de Python (sin librerías externas) en tu equipo para habilitar Ping ICMP real, tabla ARP completa, direcciones MAC, fabricantes OUI, banners HTTP y escaneo de puertos TCP directamente en esta interfaz.

Estado: No conectado · Ejecuta el agente abajo y pulsa «Conectar Agente».
Opción A — Descargar y ejecutar en Windows / macOS / Linux ⬇ Descargar .py 
python3 javier_lan_agent.py
Opción B — Lanzar directo en Linux / macOS 
curl -sSL https://javiergalilea.es/pr_red/agent/javier_lan_agent.py | python3
