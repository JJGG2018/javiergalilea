    SINCRONIZACIÓN MULTIUSUARIO

    Conexión a Backend / Base de Datos

    Elige cómo se sincronizan las posiciones y los tracks de los usuarios (3 letras). Por defecto funciona sin configuración mediante WebSocket Público + BroadcastChannel, pero puedes conectarlo a tu propio Supabase, Firebase Realtime DB o Servidor WebSocket.

    Canal Híbrido Activo de Serie:
    • Sincroniza al instante entre pestañas locales (BroadcastChannel) y entre distintos dispositivos en Internet mediante relay WebSocket público cifrado por código de sala.
    • Abre esta misma URL en tu móvil y en tu ordenador con la misma sala (ej. SALA-JG1) y verás ambos códigos de 3 letras pintando su track en vivo.
    Sincronización vía Supabase Realtime Broadcast: No requiere siquiera crear tablas SQL: utiliza los canales efímeros de baja latencia de Supabase Realtime (WebSocket Phoenix) autenticados con tu anon key, además de hacer upsert opcional si existe la tabla tracks_positions.
    Sincronización en `/rooms/{sala}/users/{ID_3_LETRAS}.json`: Publica coordenadas por REST PATCH y escucha cambios en tiempo real mediante Server-Sent Events (SSE) e interrogación adaptativa.
    Protocolo JSON estándar: El cliente envía y recibe tramas JSON con el formato: {"type":"track_pos","room":"SALA-JG1","id":"JGG","color":"#00f5d4","lat":40.4168,"lon":-3.7038,"heading":85,"speed":18.4,"ts":1730000000}
