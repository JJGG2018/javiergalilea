    Conexión a Backend / Base de Datos

    Elige cómo se sincronizan las posiciones y los tracks de los usuarios dados de alta (3 letras). Por defecto funciona sin configuración mediante WebSocket Público + BroadcastChannel, o puedes conectarlo a tu propio Supabase, Firebase Realtime DB o Servidor WebSocket.

    Canal Híbrido Activo de Serie:
    • Sincroniza al instante entre pestañas locales (BroadcastChannel) y entre distintos móviles/ordenadores en Internet mediante relay WebSocket por código de sala.
    • Solo aparecen en el mapa los usuarios que se dan de alta en la sala (ej. SALA-JG1).
    Sincronización vía Supabase Realtime Broadcast: Utiliza los canales en tiempo real de Supabase Realtime (WebSocket Phoenix) autenticados con tu anon key.
    Sincronización en `/rooms/{sala}/users/{ID_3_LETRAS}.json`: Publica coordenadas por REST y escucha todos los usuarios dados de alta en la sala.
    Protocolo JSON estándar: El cliente envía y recibe tramas JSON con el formato: {"type":"track_pos","room":"SALA-JG1","id":"JGG","color":"#00f5d4","lat":40.4168,"lon":-3.7038,"heading":85,"speed":18.4,"ts":1730000000}
